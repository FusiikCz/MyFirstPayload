================================================================================
 LAB-ONLY KEYLOGGER DEMO — DOES NOT WORK ON PUBLIC WEBSITES
================================================================================

This file is an inert example for an ISOLATED LAB ENVIRONMENT.

SAFETY GUARDS (these are not obstacles; they are why this can be public):
  1) Host guard: the script runs ONLY on "lab.local".
     "lab.local" is not a real public domain; it exists only in your lab
     network (mapped through /etc/hosts to 127.0.0.1). The code will NOT run
     in a visitor's browser on any other website.
  2) The C2 address is 127.0.0.1 (localhost); no data goes to the internet.
  3) No target paths, field names, or fingerprints from a real website.

================================================================================
 WHAT THE DEMO SHOWS (educational purpose)
================================================================================
  - how stored XSS can run JavaScript when content is displayed,
  - how JavaScript can access cookies / keystrokes / pasted text / forms,
  - how data is batched and sent to the collection server (see c2.py),
  - why CSP + HttpOnly cookies + output escaping STOP this attack
    (see DEFENSE.md).

================================================================================
 HOW TO RUN IN THE LAB
================================================================================
  1) /etc/hosts (Linux/mac) nebo C:\Windows\System32\drivers\etc\hosts (Windows):
        127.0.0.1   lab.local
  2) Start the mock website from the repository root:
        php -S 127.0.0.1:8000 -t .
  3) Start C2:        python3 c2.py (prints the token)
  4) Enter the PAYLOAD below in the mock website's "Text" field
     (http://lab.local:8000/).
     NOTE: the mock website listens on :8000; the payload points to C2 on :8080.
  5) Open the ad page (non-safe mode) in a browser; events appear in C2.
  6) Dashboard: http://127.0.0.1:8080/?token=<YOUR_TOKEN>

================================================================================
 C2 ENDPOINTS
================================================================================
